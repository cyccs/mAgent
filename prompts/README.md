# Running Coach AI Prompts

## 文件说明

- `running-coach.system.md` — AI 教练系统提示词

  这是本项目的核心文件，定义了 AI 教练生成每周跑步计划的规则和逻辑。
  修改此文件可以直接影响 AI 计划的质量和风格。

## 如何调优 Prompt

1. **修改规则**：编辑 `running-coach.system.md` 中的规则约束部分
   - 可以调整配速定义、心率区间、距离范围
   - 可以修改进度调整逻辑（升级/降级条件）
   
2. **重启开发服务器**：使修改生效
   ```
   npm run dev
   ```

3. **测试验证**：
   - 通过 Web 界面填写用户信息，生成初始计划
   - 完成训练并提交反馈数据
   - 点击"生成下周 AI 建议"观察 AI 的调整策略
   - 检查生成的计划是否符合预期规则

4. **反复迭代**：
   - 如果计划不理想，调整 prompt 中的规则描述
   - 注意 prompt 中的"必须遵守"等措辞会增强约束力
   - 可以使用更具体的描述来引导 AI 行为

## 输出格式

LLM 返回 JSON 格式的每周训练计划，经过后端校验后会：
- 修正超出约束的值（如距离自动夹紧到 1-5km）
- 使用预设的配速和心率数据覆盖 LLM 输出
- 确保训练日只能安排在用户可用的周几

因此 LLM 的输出主要影响：
- 训练日的选择与排序
- 跑步类型的分配（简单跑/正常跑/进阶跑）
- 距离的递增策略
- 训练标题文案

## 系统架构

```
用户填写信息 → LLM 生成初始计划 → 后端校验 → 存入 SQLite
用户提交反馈 → LLM 分析反馈并生成下周计划 → 后端校验 → 用户确认
```
